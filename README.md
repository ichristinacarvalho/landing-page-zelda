# 🗡️ Landing Page - The Legend of Zelda

> Uma página de destino (landing page) temática, moderna e responsiva, inspirada no universo da clássica franquia de jogos The Legend of Zelda.

---

## 🚀 Sobre o Projeto
Este projeto foi desenvolvido com foco na estruturação de layouts limpos, aplicação de boas práticas de estilização com CSS moderno e construção de páginas totalmente adaptáveis a diferentes tamanhos de tela (design responsivo). A página busca transmitir a identidade visual imersiva do jogo através de um design atraente e organizado.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias:
* **HTML5:** Estruturação semântica e organização dos elementos da página.
* **CSS3:** Estilização visual avançada, layouts estruturados e design responsivo.
* **Git & GitHub:** Controle de versão e hospedagem do código.

---

## ⚙️ Funcionalidades
* **Design Responsivo:** Layout adaptado para visualização ideal em computadores, tablets e smartphones.
* **Identidade Visual Temática:** Uso de paleta de cores e elementos visuais inspirados na franquia.
* **Estrutura Moderna:** Seções bem definidas para apresentação de conteúdos e call to action (CTA).
